# 任务：MBTI 场景问卷的「题库」（12 道中文题）

## 交付物

只输出一个 **JavaScript 数组字面量**，赋值给 `var QUESTIONS`。
**不要**输出函数、不要解释、不要 markdown 围栏、不要输出其它任何东西。

```js
var QUESTIONS = [
  { id: 'ie-1', axis: 'IE', scene: '……', ask: '……',
    options: [ { text: '……', picks: 'E' }, { text: '……', picks: 'I' } ] },
  // ……
];
```

## 数量与分布（**必须严格遵守**）

- 共 **12 道**，四个维度各 **3 道**
- id 命名：`ie-1/ie-2/ie-3`、`ns-1/ns-2/ns-3`、`tf-1/tf-2/tf-3`、`pj-1/pj-2/pj-3`

## 字段说明

- `scene` —— 一句话描述一个**具体场景**（要有人、有事、有细节）
- `ask` —— 紧跟场景的提问句，统一是"你觉得他……"这种口吻
- `options` —— **恰好两个**，`picks` 必须是该维度的两个字母之一（见下表）
- 每题**不要**出现"我不知道"选项（由程序统一加）

## 维度定义（**picks 与含义必须对应正确，这是最容易错的地方**）

| axis | picks 字母 | 这一端的人是什么样 |
|---|---|---|
| `IE` | `I` | 独处充电、先想后说、喜欢小圈子、人多会累 |
| `IE` | `E` | 与人互动充电、边说边想、喜欢热闹、独处会闷 |
| `NS` | `N` | 关注可能性与寓意、爱抽象联想、说话跳跃、爱聊"如果" |
| `NS` | `S` | 关注事实与细节、务实、按经验办事、爱聊"具体怎么做" |
| `TF` | `T` | 先讲道理与规则、就事论事、敢指出问题、不太绕弯 |
| `TF` | `F` | 先照顾感受与关系、讲人情、怕伤和气、先安慰再讲事 |
| `PJ` | `P` | 留余地、随时改主意、先动手再定、讨厌被计划绑住 |
| `PJ` | `J` | 早定计划、按步骤来、先定后做、讨厌临场变卦 |

## 写作要求

1. 场景必须是**日常生活里真的会发生的事**。可参考：被临时叫去聚会、点外卖纠结、
   团队出岔子、朋友来诉苦、收到坏消息、要买个大件、和陌生人拼车、
   临出门发现下雨、有人当众否定他的方案、给朋友挑生日礼物、
   群里有人吵架、周末突然多出一天假、临时被换任务、朋友迟到了。
2. 两个选项都要**具体、有画面、篇幅相当**，不能一边长一边短，
   也**不能明显一个好一个坏**（会诱导作答）。
3. 语气像朋友间聊天，短句。**不要**出现"倾向于""通常来说""一般来说""从心理学角度"这类词。
4. **不要**直接问类型（禁止"你觉得他是内向还是外向"这种写法）。
5. 同一维度的 3 道题要**从不同侧面切入**，不要三道题其实在问同一件事。
6. 每道题的 `options[0]` / `options[1]` 顺序可以自由安排（不要 12 道题都把一个字母放前面）。

## 示例（照这个质量水平写，但内容要你自己想）

```js
{ id: 'ie-1', axis: 'IE', scene: '周五下班前十分钟，同事临时喊他去唱歌',
  ask: '你觉得他会怎么回应？',
  options: [
    { text: '先答应下来，人多热闹，唱到几点都行', picks: 'E' },
    { text: '找个理由推掉，说想回去歇着', picks: 'I' }
  ] }
```

## 自检（输出前在心里过一遍）

- 12 道题，id 与 axis 一一对应，没有重复 id
- 每道题恰好 2 个 option，`picks` 都是合法字母且与题目想考察的维度一致
- 没有任何一道题两个选项都指向同一端
